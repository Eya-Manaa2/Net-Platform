# Lab 2 - Context Engineering

## Objectif

Donnez à votre projet Lab 1 un "cerveau", puis prouvez qu'il fonctionne.

## Livrables

1. **AGENTS.md** - Le README de votre projet pour les agents : setup, tests, style de code, et garde-fous
2. **Une Skill réutilisable** - Un dossier + SKILL.md
3. **Comparaison avant/après** - Exécutez la même tâche avec et sans le bon contexte, et mesurez le succès au premier passage

## Pourquoi

La structure — pas un modèle plus intelligent — est ce qui vous fait avancer vers un ingénierie agentique fiable. C'est la compétence durable et transférable de tout le cours.

## Étapes

### 1. Créer AGENTS.md

Un AGENTS.md est un README spécialisé pour les agents de codage. Il doit contenir :

- **Setup** : Comment installer et configurer le projet
- **Tests** : Comment exécuter les tests
- **Style de code** : Conventions et standards
- **Garde-fous** : Vérifications et validations
- **Architecture** : Structure du projet
- **Dépendances** : Bibliothèques et versions

### 2. Créer une Skill

Une Skill est un composant réutilisable qui peut être utilisé par différents agents. Elle doit contenir :

- **Dossier de la skill** : Code et ressources
- **SKILL.md** : Documentation de la skill
- **Exemples d'utilisation** : Cas d'usage
- **Tests** : Validation de la skill

### 3. Comparaison Avant/Après

Testez l'efficacité du contexte en :

1. Exécutant une tâche SANS AGENTS.md/Skill
2. Exécutant la même tâche AVEC AGENTS.md/Skill
3. Comparant les résultats :
   - Taux de succès au premier passage
   - Nombre de corrections nécessaires
   - Temps total
   - Qualité du code
